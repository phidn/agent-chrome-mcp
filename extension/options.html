Agent Chrome MCP

Profile label for multi-profile routing

Checking connection…

When you load this extension in more than one Chrome profile, each profile needs a distinct label so your MCP client can target the right one. Pick something meaningful like work or personal, then ask Claude, Codex, or Antigravity to use the work profile, or let it call switch_browser / list_browsers. You can give one profile several labels (aliases) by separating them with commas, e.g. work, personal — either client can then target this profile by any of them.

Lowercase, no spaces recommended. Separate multiple labels with commas. Max 60 characters each.
